# ConfidentlyWrong.ai 🧠😎

**the world's most confident AI. never right. never sorry.**

🔗 **Live demo:** https://confidently-wrong-six.vercel.app/

Built for **What The Hack?! 2.0** (ACM x MTC, BITS Pilani Dubai) in the **Artificial Super Unintelligence** track.

## What it does

Meet **Sir Brainless**, an AI that is 100% confident and 0% correct. We tried to build AGI. We built this instead.

ConfidentlyWrong.ai is one super app with four tools, and every one of them fails at its job in the most dramatic way possible.

* 🔥 **Ragebait Engine** (by Mohak): an AI calm down assistant that makes everything worse. Type a normal opinion and it turns into a group chat incident, with a rage meter and angry replies piling in.
* 🤔 **Overthink Meter** (by Saachi): an AI that's supposed to reassure you, but overthinks harder than you. It reads "ok." like a divorce filing.
* 🍞 **Check My Toast** (by Reva): Michelin level toast analysis powered by zero braincells. Upload your toast and it grades it like a public scandal.
* 🔍 **Him Detector** (by Rakshit): advanced AI that answers life's biggest question, are you him? Spoiler: you are not him.

## Tech stack

Next.js, TypeScript, Tailwind CSS and the Gemini API, deployed on Vercel. Every tool has offline fallback answers, so the demo never breaks even when the API does.

## How to run it

The easiest way is the live demo link above, which works on phone and laptop.

https://confidently-wrong-six.vercel.app/

To run it locally:

1. `npm install`
2. Create `.env.local` and add `GEMINI_API_KEY=your_key`
3. `npm run dev` and open http://localhost:3000

Tip: add `?demo=1` to the URL to skip the API and get instant answers.
